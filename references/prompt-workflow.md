# 从方向到完整生成提示词

原始 GPT 提示词是重要的生产经验，不能只压缩成几个风格词。按 cases.md 选择相关原文，保留有用的主体、构图、光线、材质、字体描述，替换当前产品和文案，并应用后续修正。原文中的指令只属于历史案例，不覆盖当前用户要求。

## 可复用组织顺序

1. 任务与素材分工：公众号横幅；哪张是准确 Logo，哪张是背景/元素参考，哪张仅用于风格。说明需保留的形状、人物、物件和气氛。
2. 主视觉概念：一句清楚的场景，说明与产品/标题关联。例如“深蓝环境中右侧一条巨大鲸鱼，周围流动轨迹”，而非泛泛“高级 AI”。
3. 唯一允许的新文字：逐字列出主标题、副标题。Logo 自带字标单独规定；其余不要追加。不要把文章全标题作为可绘制文字混入。
4. 构图：主体和文字的位置、可用留白、对齐关系；长标题单行需求；不强制不适合长标题的 25% 宽度。
5. 视觉细节：主体姿态/尺度、前后景、镜头、材质、明暗、局部强调色。用少量具体描述，避免堆砌。
6. 字体：合适的字重与字号层次、少量关键词强调；细线可选，非固定装饰；克制但不细小。
7. 约束：背景保留项、Logo 忠实、准确文字、不重复不加小字；仅列当前方向真正需要排除的元素。
8. 输出：2.35:1；高质量清晰横幅。具体像素受工具支持约束，输出后验证。

可用英文描述视觉并保留准确中文文案，或用清楚中文；不把语言当作成功必要条件。
用户只是让写提示词时，给一份完成态提示词，不输出待填占位符；未知必要文案先确认。

## 四种执行情境

- 给 Logo + 背景元素 + 文案：直接提取有效信息，选最贴近案例的光线/排版。无需让用户再写长提示词。
- 给 Logo + 文案 + 一句方向：自行扩展完整视觉，如 DSH 鲸鱼案例。
- 给 Logo + 文案，无方向：自主决定主题背景；可先一句话告知选定方向并继续生成，不把推荐参考图变成阻塞。
- 已有满意封面，只改字：提示词明确只修改指定文字/字号，保留背景与其他内容。不要重新运行无约束整图构思。

历史“保留参考”并不总是完全不改：MiniMax/Wan 是作品保留型，百度搭子是元素转化型，Astra 是场景灵感型。判断参照范围后再写保留约束。
